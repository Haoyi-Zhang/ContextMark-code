# Novelty and evidence boundary

The closest artifact-local code-watermark papers strengthen carriers, transformations, tracing, or attacks. LineageMark studies repeated multi-user insertion along model-derivation chains. Authenticated Contradictions shows that provenance and watermark layers can conflict when verified independently. LIME already combines watermarks, signatures, and oblivious transfer for data-recipient tracing. Supply-chain systems such as in-toto and CHAINIAC authenticate detached histories or consistency views.

The paper's narrower increment is a common software-lineage contract for public authorization, host binding, signed parents, exact tips, terminal issue attempts, and adaptive first-hit accounting. The finite threshold construction is a non-vacuity instance based on classical interpolation; it is not a new secret-sharing primitive. The residual reader is a polynomial implementation of the same consistency predicate, with an equivalence proof and exhaustive finite differential check.

No bounded literature search proves priority. No third-party learned watermark or production attestation stack is assigned an empirical score. The project compares declared guarantee surfaces and records the unavailable production execution as a local gap.
